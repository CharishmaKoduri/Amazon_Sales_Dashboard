### Project Overview
---
This Power BI project analyzes an e-commerce sales dataset to uncover business insights related to sales, profit, quantity, shipment cost, customer segments, product categories, and state-wise performance. The interactive dashboard enables decision-makers to monitor KPIs, identify high-performing categories, and understand sales trends across different dimensions.



### Dataset

**Dataset:** Amazon E-Commerce Sales Dataset

The dataset contains transactional sales information including:

* Order Date
* Category
* Sub-Category
* Segment
* State
* Sales
* Profit
* Quantity
* Discount
* Shipment Cost


### Dashboard Features

The dashboard provides interactive visualizations including:

* KPI Cards

  * Total Sales
  * Total Profit
  * Total Quantity Sold
  * Total Shipment Cost

* Sales by Category

* Monthly Sales Trend

* Sales & Profit by Customer Segment

* Category & Sub-Category Tree Map

* Average Discount by Sub-Category

* Profit by State

### Data Preparation

The following preprocessing steps were performed:

* Imported dataset into Power BI.
* Removed duplicate records.
* Checked and handled missing values.
* Corrected data types.
* Formatted date columns.
* Cleaned categorical values.
* Created relationships where required.
* Built calculated measures using DAX.



### Dashboard Preview

The Power BI dashboard provides an interactive overview of:

* Sales Performance
* Profit Analysis
* Monthly Trends
* Customer Segments
* Product Categories
* State-wise Profit
* Discount Analysis

Users can interact with visuals using filters and drill-down functionality to gain deeper business insights.
